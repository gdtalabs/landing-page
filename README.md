# GDtal Labs Landing Page

A lightweight one-page landing site for `gdtallabs.com`.

## Files
- `index.html`
- `style.css`
- `script.js`
- `assets/gdtal-icon.jpg`
- `assets/gdtal-logo.jpg`

## Deploy
Upload the folder to your GitHub repository or import the repository into Vercel.

## Before going live
Update the email address in the `Discuss a Project` button if needed:

```html
mailto:hello@gdtallabs.com
```

You can also replace or add client case studies under the `Selected Work` section.
